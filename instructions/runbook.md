# Операционки Образа — как запускать руками

## Посевы
- Шаблон DM админу: `Привет! Хочу посев в вашем канале — нативная подборка 3 образов (фото + текст ~600 зн) + промокод. Сколько стоит пост без удаления 48ч? Есть стата за 7 дней?`
- Оплата: только после статы, без предоплаты 100% незнакомым. Маркировка erid через ОРД.

## UGC-бриф блогерке (отдай как есть)
```
Задача: снять 1 видео 20-35с вертикаль 9:16
Хук (0-2с): «Собрала 3 образа дешевле чем 1 в ТЦ — смотри где»
Тело: листай образы из Obraz (скринкаст или примерка), покажи цены 4 площадок
CTA: «Ссылка в шапке + промокод XXX -15% на Obraz»
Оплата: 15% с каждой оплаты приведённых 3-6 мес, стата в /stats (прозрачно)
Запрет: без упоминания Instagram-рекламы, без фикса
```

## Промокоды
- Формат: `OBRAZ_XXX` (XXX — ник блогерки/канала), скидка 10-15% на 1 мес
- Учёт: `t.me/obraz_bot?start=ref_XXX` + промокод в пейволе
- Выплаты: после 2-го платежа подписчицы, холд 30 дней, ручной реестр фаза 0
