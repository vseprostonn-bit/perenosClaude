# Obraz - навигация

Совместный проект: Yorren + Александр Ермошин (Саша). Приложение для девушек по подбору образа с интеграцией селлеров Wildberries / Ozon / Lamoda.

## Статус

Этап 0 закрыт 2026-08-24 (все решения - в ROADMAP). Идёт Этап 1 - фаза 0: TG-бот + пейвол на веб-кассе + реф-система, техплан `plans/2026-08-24-faza-0-bot-i-payvol.md`.
Модель: платная подписка (A/B 199/299/499) - основной доход; блогерам 15% рекуррентно 3-6 мес с оплат приведённых; CPA маркетплейсов - дополнительный поток. Оплата: касса на своём домене (Robokassa), Stars не используем. Роли: Саша - блогеры и трафик, Yorren - код/платёжка/каталог/юр, 50/50.

## Порядок чтения в начале сессии

1. `START.md` - выжимка всего проекта, быстрый вход в контекст.
2. `ROADMAP.md` - этапы, задачи, статусы, критерии выхода.
3. По мере задачи: `docs/2026-08-24-videnie-i-mehanika.md` (модель и блогерская механика), `docs/2026-08-24-mehanika-kataloga-i-ii.md` (каталог, сборка образов, самообучение), `docs/2026-08-24-razbor-idei-plyusy-minusy.md` (рынок и конкуренты).

## Правила

1. Отвечать на русском. Без длинного тире, только дефис.
2. Цифры (комиссии, цены, доли рынка) в документах - всегда с датой фиксации: они протухают.
3. Секреты - только в `.env`. Нужна переменная - `grep "^VAR=" .env`, целиком файл не читать.
4. `git add` поимённо. Никаких `git add .` и `git add -A`.
5. Большая фича (больше часа работы) - сначала план в `plans/`.
6. Локальные данные и выгрузки - в `data/` (в `.gitignore`, в git не попадают).
7. Не публиковать ничего от имени проекта без согласия обоих партнёров.
