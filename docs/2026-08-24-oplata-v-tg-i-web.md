# Оплата: как принимаем деньги в TG и на вебе параллельно

Дата: 2026-08-24. Разбор вопроса №4 созвона. Контекст: ИП Yorren с ОКВЭДами под интернет-услуги и расчётным счётом уже есть. Аудитория - РФ (карты МИР, СБП).

## Коротко - ответ

Да, принимать оплату можем, и «TG + веб параллельно» - не компромисс, а правильная архитектура: **продукт живёт в Telegram, касса живёт на нашем веб-домене**. Одна платёжная инфраструктура, две витрины. Ниже почему.

## Три способа взять деньги в Telegram и их правда (2026)

### 1. Telegram Stars - формально обязательный, экономически неподъёмный

По Bot Developer Terms (п. 6.2, действует с 12.06.2025) все цифровые товары и услуги внутри ботов и Mini Apps должны продаваться только за Stars. Но:

- потери 35-45% по пути «рубль пользователя -> рубль на р/с»: Apple/Google забирают ~30% при покупке звёзд, вывод разработчику - только через Fragment в TON (курс ~0,013$ за звезду при цене покупки ~0,02$), холд 21 день, комиссия Fragment до 5%, конвертация TON в рубли ещё 2-5%;
- выплата приходит криптой (TON): по 259-ФЗ владеть и продавать можно, но для ИП это отдельный налоговый контур - НДФЛ по 3-НДФЛ, с ПСН/НПД крипта несовместима. Бухгалтерский головняк ради потери трети выручки;
- подписки в Stars есть (период ровно 30 дней), но экономику это не спасает.

**Вердикт: на старте не используем.** Вернёмся к вопросу, только если появится большая iOS-аудитория, которой неудобно платить иначе.

### 2. Bot Payments API через ЮKassa / Robokassa - работает, но не для цифры

Инвойс прямо в интерфейсе бота, деньги идут через российского провайдера на наш р/с, Telegram комиссию не берёт. Нюанс: по ToS этот канал - для физических товаров; цифровая подписка формально обязана идти через Stars. При этом сами Robokassa и ЮKassa открыто продают решения «приём оплаты цифровых товаров в Telegram» - правила платформы и практика рынка конфликтуют. Энфорсмент Telegram избирательный (в первую очередь ограничения в store-версиях клиентов на iOS).

**Вердикт: не основа. Можно держать как запасной канал.**

### 3. Внешняя веб-страница оплаты - основа (массовая практика РФ)

Бот или Mini App даёт кнопку, она открывает страницу оплаты на нашем домене (эквайринг + СБП). Сама транзакция происходит вне Telegram - юрисдикция платформы на неё не распространяется. Известных массовых банов российских ботов за платёжные ссылки нет; связка «в TG продукт - на сайте касса» - стандарт рынка.

**Вердикт: наша основа. Заодно это и есть веб-версия - та же страница обслуживает и сайт, и TG.**

## Схема целиком

```text
TG-бот / Mini App            Веб-сайт (SEO)
        \                       /
         кнопка «оформить подписку»
                  |
   страница оплаты на нашем домене
   (карта МИР / СБП, оферта, чек)
                  |
   провайдер -> деньги на р/с ИП
                  |
   вебхук -> наш бэкенд -> доступ открыт,
   метка блогера засчитана (15%)
```

Рекуррент (автопродление): автосписания по сохранённой карте у провайдера + «Подписки СБП» (сервис НСПК, работает в ~120 банках, самый дешёвый канал).

## Провайдеры - сравнение для ИП (2026-08)

| Провайдер | Карты | СБП | Рекуррент | Чеки 54-ФЗ без своей кассы | Вход |
|---|---|---|---|---|---|
| Robokassa | 3,9% | 2,7% | есть, вкл. СБП push | Робочеки - бесплатно (агентская схема) | 0 руб |
| ЮKassa | от 2,8% + 1% за чеки | 0,4-0,7% | автоплатежи по карте | «Чеки от ЮKassa» +1% | 0 руб |
| CloudPayments | ~3,9% (инд.) | есть | сильнейший API | чековое решение 1500 руб/год | 1900 руб |
| Продамус | 3,8% (+1 п.п. за рекуррент) | есть | есть | включены | 10 000 руб |

**Рекомендация: старт на Robokassa** - ноль фиксированных расходов (вход 0, чеки 0, касса не нужна), рекурренты включая СБП, официально работают с цифровыми товарами и Telegram. При росте оборота пересмотреть в пользу ЮKassa (СБП 0,4-0,7% - дешевле всех) или CloudPayments (лучший API рекуррентов).

## Чеки и налоги

- **ККТ обязательна** при приёме денег от физлиц за подписку - исключений для «цифры» нет. Легально не покупать кассу: агентская фискализация (Робочеки - 0 руб) или облачная касса (Атол Онлайн 1500-2500 руб/мес). Берём агентскую.
- **Налоги:** доход от подписок - IT-доход ИП, идёт по действующей схеме (до конца 2026 - НДФЛ, с 2027 - УСН 6%; ПСН этого не касается). Сверить детали с бухгалтером при подключении.
- На сайте нужны: оферта, политика ПД (152-ФЗ), реквизиты - сделаем вместе со страницей оплаты.

## Экономика на подписке 299 руб

| Канал | Теряем | Получаем |
|---|---|---|
| Веб: карта (Robokassa 3,9%) | ~12 руб | ~287 руб |
| Веб: СБП (2,7% / 0,4-0,7%) | 2-8 руб | 291-297 руб |
| Telegram Stars | 105-135 руб + крипта | 165-195 руб |

Разница между внешней оплатой и Stars - треть выручки. Вопрос закрыт цифрами.

## Что делаем (войдёт в фазу 0)

1. [ ] Договор с Robokassa на ИП + Робочеки.
2. [ ] Страница пейвола на нашем домене: тарифы, оплата картой/СБП, оферта, чек. Нужна уже в фазе 0 - бот будет вести на неё.
3. [ ] Вебхук оплаты -> бэкенд: открытие доступа + начисление 15% блогеру по метке.
4. [ ] Подписки СБП + автосписания карт - рекуррент с первого дня (блогерская модель 15% на 3-6 мес живёт на рекурренте).
5. [ ] Мониторим политику Telegram по внешним платежам; в Mini App держим формулировки нейтральными («оформить на сайте»).
