## 2. TG Mini App UX — гайд

- **Viewport:** `viewportStableHeight`, safe area, без горизонтали 360px, thumb-zone CTA внизу
- **Theme:** `themeParams` (bg, text, hint, button) — чекать контраст 4.5:1 на светлой и тёмной, 1 акцент-цвет CTA (розовый/коралл для fashion, не синий как у B2B)
- **Навигация:** BackButton, MainButton («Открыть 3 образа бесплатно»), HapticFeedback на сохранении/покупке
- **Онбординг:** 3 шага, прогресс-бар, пропуск
- **Состояния:** empty (нет фильтров), loading skeleton, ошибка сети, битый товар (in_stock=false — бейдж «нет в наличии, есть аналог»)

## 3. Лендинг fashion-подписки — структура, которая конвертит

- **Webflow Top-100 CR + CXL:** Hero с цифрой («50 образов · 4 маркетплейса · 2 мин») + соцдок сразу, боль 3 карточки, 3 шага, демо ленты (живое, не мокап), прайс с якорем (перечеркнуто 990 → 299), FAQ 3 возражения (дорого/не мой размер/не мой стиль), CTA каждые 1.5 экрана, липкий хедер, F-паттерн влево-вверх
- **Refactoring UI + Baymard:** воздух 60%, 1 экран = 1 действие, 8px сетка, форма оплаты — 1 поле (СБП/МИР), доверие — Робочеки, ИП, erid
- **AIDA/PAS:** Attention — «Готовый образ за 10 сек, где купить дешевле», Agitation — «часы на WB/Pinterest», Solution — 3 шага + демо, Action — «Открыть 3 образа — бесплатно»

## 4. Визуал fashion — палитра/типографика/3D

- **Палитра (светлая, женская, не B2B-синяя):** bg #FFF8F6 (тёплый), text #1A1A1E, акцент CTA #FF4D6A (коралл), вторичный #FF8FA3, бордер #F2E6E2. Тёмная тема TG: bg #1A1212, акцент тот же, контраст 4.5:1
- **Шрифты:** заголовки Manrope 700, текст Inter 400/500 — 2 шрифта, free
- **3D:** 1 материал (мягкий пластик/стекло), изометрия стопки образов, мягкий студийный свет — Магнифик промпт + Spline интерактив (козырь C4D Саши)
- **Фото:** cover 4:5, 1080×1350, без фильтров, чистка фона Remove.bg — генерим Магнификом

## 5. Пейвол-платеж — UX, который не сливает CR

- Baymard: 1 экран, 3 тарифа (199/299/499) с якорем — средний подсвечен «Популярный», перечеркнуто 990, бейдж «-70%», кнопка 1 цвета во всю ширину thumb-zone
- Доверие: «МИР/СБП · чек Робочеки · отмена в 1 клик», FAQ «как отписаться» — снимает страх подписки

## 6. Топ-5 ошибок дизайна fashion (не повторять)

1. Тёмный B2B-ленд (синий/чёрный) — женской ЦА холодно → тёплый светлый
2. Мелкая лента 3 колонки на мобиле — не видно → 2 колонки masonry
3. Нет сравнения цен — нет ценности → 4 бейджа цены в карточке
4. Пейвол без якоря — берут 199 и churn → якорь 990→299, средний подсвечен
5. Фото без единого света — дешево → 1 свет, 1 материал
