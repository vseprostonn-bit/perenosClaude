# Маркетинговый план Obraz — Фаза 0 (тест спроса)

Дата: 2026-08-25. Автор: Саша + фабрика. Источник: START.md, ROADMAP.md, plans/2026-08-24-faza-0-bot-i-payvol.md
Статус: WIP. Бюджет фазы: 20-30к руб. Срок: 2-4 недели. Цель: доказать конверсию регистрация → оплата ≥3%.

## 1. Продукт и оффер фазы 0

**Что продаём:** TG-бот с лентой готовых образов (50-100 шт, сегменты: учёба/офис, свидание, база осень). 3-5 образов бесплатно после анкеты (размер/стиль/бюджет) → пейвол 199/299/499 руб/мес (A/B по tg_id).

**Ценность в 1 фразе:** «Готовый образ за 10 сек + кнопка где купить дешевле на 4 маркетплейсах».

**Почему заплатят:** экономит часы на WB/Pinterest, кросс-площадочный выбор цены, подбор под размер/бюджет.

## 2. Аудитория

- Ядро: девушки 18-28, Москва/СПб/миллионники, покупают одежду на WB/Ozon, сидят в TG и Pinterest.
- Сегменты: студентки (бюджет low), офисные (smart casual), дейтинг (вечерние образы).
- Где живут: женские TG-каналы (мода, стиль, капсулы), VK клипы, YouTube Shorts.

## 3. Воронка фазы 0

```
Посев в TG-канале (пост с промокодом блогерки)
  → t.me/obraz_bot?start=ref_XXX (фиксация первого касания)
  → /start → анкета (размер, стиль, бюджет) — 30 сек
  → выдача 3-5 образов (карточка: фото + вещи + цены + «где купить»)
  → 4-й образ → пейвол-экран (цена из бакета) → кнопка «Оформить»
  → страница оплаты Robokassa (МИР/СБП, оферта, чек Робочеки)
  → оплата → подписка 30 дней → уведомление в бот → доступ открыт
  → события в `events` на каждом шаге
```

**Метрики go/no-go (ROADMAP):**

| Метрика | Порог | Что меряем |
|---|---|---|
| Цена регистрации | ≤50 руб | бюджет посева / регистрации |
| Регистрация → оплата | ≥3-5% (стоп <2% после пивота) | events + payments |
| CAC оплатившей | ≤3× подписки (≤900р при 299р) | бюджет / оплаты |
| Возврат D7 | ≥20% | повторный вход в бота |

Не сошлось → пивот цены/оффера, повторный замер. 2-й провал → закрываем, потеряли 30к и месяц, не полгода.

## 4. Каналы фазы 0 (только ручные, без Ads)

**A. Пилот UGC-блогерки (приоритет 1):**
- 3-5 микро-блогерок 5-30к подписчиков, уже снимают образы/капсулы.
- Оффер: личный промокод (скидка девочке 10-15% на 1-й мес) + 15% с оплат приведённых 3-6 мес рекуррентно, выплаты как самозанятым, статистика в /stats (клики/реги/оплаты).
- Первый кандидат — Виктория НН, дальше знакомые + холодные DM.
- Контент: 1 кружок/Reels-скрипт + пост «собрала образы в Obraz — смотри».
- Цель: 0 затрат на старте, тест креатива и конверсии реф-ссылки.

**B. Посевы в женских TG-каналах (бюджет 20-30к):**
- 3-5 каналов 20-100к, ER ≥2%, женская аудитория 70%+.
- Формат: нативный пост + 2-3 фото образов + промокод канала.
- Закупка через Telemetr/TGStat + прямые DM админам (дешевле бирж на 20-30%).
- Тест: 3 канала × ~7к = 21к, смотрим цену регистрации, докупаем победителя.

**Что НЕ делаем в фазе 0:** Telegram Ads (дорого, нужен прогрев), таргет VK, контекст, Instagram (запрет рекламы с 09.2025).
