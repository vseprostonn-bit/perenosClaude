## 2. Кейсы creator commerce (что копировать)

- **LTK / ShopMy ($2млрд / $1.5млрд):** каждый образ — лендинг с товарами + кнопка купить + deeplink sub_id. Креатор собирает из каталога. Взять: UGC-конструктор этапа 3 (MVP на Notion/Airtable без кода).
- **Wibes (WB) + витрины ЯМ:** фрагменты внутри площадок, но без кросс-площадочности — наш козырь 4 маркетплейса (выбор где дешевле).
- **Aesty (iOS, ИИ-гардероб):** 999р/мес, 18 оценок — завышена цена, нет покупки. Взять: цена 199/299 + кнопка «где купить» сразу.
