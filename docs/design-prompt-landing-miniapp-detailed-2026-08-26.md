# Детальный промт — лендинг + TG Mini App (глубина, градиенты, анимации, премиум-ощущение)

Дата: 2026-08-25. Проект: Образ. Исполнитель: дизайнер / дизайн-агент / Магнифик / Figma / Spline / Claude.
Цель: премиальный, тёплый, живой дизайн с ощущением глубины и плавных анимаций, который конвертит (лендинг) и удерживает (мини-апп).

---

## 1. РОЛЬ

Ты — арт-директор премиум-модного продукта. Ты делаешь не «красиво», а «премиально и конвертирующе»: глубина создаёт ценность, градиенты — настроение, анимации — удовольствие. Каждый элемент работает на одну эмоцию: «это моё, это для меня, это дорого стоит — но доступно».

## 2. ЗАДАЧА

Спроектировать две поверхности с единой дизайн-системой:

**А) Лендинг** (пейвол/промо на домене, конвертит в оплату подписки 199/299/499 ₽)
**Б) Telegram Mini App** (лента образов + карточка + квиз + пейвол, удерживает и вовлекает)

Обе — мобильный-первый (360–430px), ретина, светлая/тёмная тема ТГ, 60 fps анимации, <2с загрузка.

## 3. ВИЗУАЛЬНЫЙ СТИЛЬ — «ТЁПЛАЯ ГЛУБИНА»

### 3.1 Палитра (градиенты обязательны)

Светлая тема:
- Фон: тёплый кремовый градиент `linear-gradient(180deg, #FFF8F6 0%, #FFEDE8 100%)` — не плоский, а «светящийся снизу»
- Поверхности: полупрозрачные карточки `rgba(255,255,255,0.72)` + backdrop-blur(20px) — эффект «матового стекла над кремом»
- Акцент: коралловый градиент `linear-gradient(135deg, #FF4D6A 0%, #FF8FA3 100%)` — для CTA, бейджей, прогресса
- Вторичный: персиковый градиент `linear-gradient(135deg, #FFD5C2 0%, #FFE4D6 100%)` — для фонов секций, подложек
- Тёмная тема ТГ: `#1A1212` фон, карточки `rgba(35,25,25,0.85)`, тот же коралловый акцент

Тёмная тема (для контраста и «премиум» в некоторых секциях ленда):
- Глубокий графит `#14110F` → тёплый коричневый `#201A16`
- Акцент остаётся коралловым — контраст с тёмным = «дорого»

### 3.2 Глубина (слои, тени, параллакс)

- **3 слоя глубины:** фон (градиент) → контент (карточки с тенью) → акценты (плавающие элементы с blur)
- Тени многослойные: `box-shadow: 0 4px 6px rgba(255,77,106,0.06), 0 10px 24px rgba(255,143,163,0.08)` — мягкие, тёплые, «воздушные»
- **Параллакс при скролле** (лендинг): фоновые градиенты и декоративные элементы двигаются медленнее контента (0.3–0.6×)
- **Плавающие 3D-элементы** (лендинг): стопка карточек образов, кнопки маркетплейсов — изометрия, мягкий пластик, тёплый свет, мягкие тени
- Карточки в мини-аппе: при тапе — подъём `translateY(-4px)` + усиление тени + лёгкий масштаб 1.02 (эффект «всплывает»)

### 3.3 Градиенты — где и как

| Элемент | Градиент | Зачем |
|---|---|---|
| Фон ленда | Кремовый вертикальный | Тепло, не плоско |
| CTA-кнопки | Коралловый 135° | Энергия, действие |
| Бейджи цен | Персиковый 135° | Мягкость, не агрессия |
| Прогресс-бар квиза | Коралловый горизонтальный | Ощущение движения |
| Подложки секций | Персиковый/кремовый радиальный | Глубина без резких границ |
| Тёмный фон (лендинг секции) | Графит→коричневый | Премиум-контраст |

Правило: градиенты всегда мягкие (2–3 цвета, один угол, без резких переходов), никогда не кислотные.

## 4. АНИМАЦИИ — «ПРИЯТНЫЕ ВСПЛЫВАЮЩИЕ»

### 4.1 Принципы

- **Плавность:** все анимации `ease-out` или `cubic-bezier(0.16, 1, 0.3, 1)` (spring-like), длительность 200–500 мс
- **Каскадность:** элементы появляются последовательно с задержкой 50–100 мс (не все сразу)
- **Направление:** снизу вверх + лёгкий масштаб (0.96 → 1.0) + прозрачность (0 → 1) — «всплывает»
- **Никакой резкости:** без `linear`, без `bounce`, без дёргания

### 4.2 Лендинг (при скролле)

- Секции появляются при входе во вьюпорт: `opacity 0→1, translateY 24px→0, scale 0.98→1`, длительность 400 мс, задержка 0 мс для первой карточки, +80 мс для каждой следующей
- Заголовки: появление слева `translateX -12px→0` + прозрачность
- Кнопки: hover — подъём `translateY(-2px)` + усиление тени + лёгкий масштаб 1.03, длительность 150 мс
- 3D-элементы (стопка карточек): медленное вращение 8–12с цикл, при скролле — наклон `rotateX/rotateY` до 10°
- Цены/бейджи: при появлении — лёгкий «пульс» масштаб 1.0→1.05→1.0, 300 мс
- Демо-лента: карточки появляются каскадом 100 мс интервал

### 4.3 Мини-апп (интерактив)

- Переход экранов: слайд снизу вверх + прозрачность (300 мс, `ease-out`)
- Карточки в ленте: при тапе — подъём + масштаб 1.02 + тень усиливается (150 мс)
- Квиз: при выборе варианта — галочка появляется с масштаб 0.5→1.0 + цвет фона плавно меняется на акцент (200 мс)
- Пейвол: при переключении тарифа — карточка подсвечивается градиентом + лёгкий «всплеск» (масштаб 1.0→1.03→1.0)
- Успешная оплата: конфетти/всплеск градиентом коралловым (300 мс) + галочка масштаб 0→1.2→1.0
- Пульсация «Избранное»: сердце масштаб 0.8→1.1→1.0 (250 мс)

### 4.4 Что НЕ делать

- Никаких `animation: spin` бесконечных
- Никаких резких `linear` переходов
- Никаких анимаций >600 мс (пользователь ждёт)
- Никаких анимаций при быстрой прокрутке (уважение к времени)

## 5. UI/UX — ПРИНЦИПЫ

### 5.1 Типографика

- Шрифты: **Manrope 700** (заголовки) + **Inter 400/500** (текст) — 2 шрифта, не больше
- Размеры (лендинг): H1 42px, H2 32px, H3 24px, тело 16px, мелкий 13px
- Размеры (мини-апп): H1 24px, H2 20px, H3 17px, тело 14px, мелкий 12px
- Межстрочный: заголовки 1.2, текст 1.5–1.6
- Цвет текста: `#1A1A1E` (почти чёрный, но мягче), подсказки `#9A8F8F`

### 5.2 Сетка и отступы

- Сетка 8px (все отступы кратны 8)
- Мобилка: 16px боковые поля, 24px между секциями
- Воздух: 60% экрана — пустота (не жалей)
- Радиус карточек: 16–20px (мягкий, «живой»)

### 5.3 Компоненты

**Кнопки:**
- Primary: градиент коралловый, радиус 14, высота 48–52, шрифт 16–17, вес 600
- Secondary: белый/прозрачный с бордером `#F2E6E2`, радиус 14
- Ghost: текст с подчёркиванием, без фона
- Состояния: hover подъём+тень, active масштаб 0.98, disabled прозрачность 0.4

**Карточки:**
- Радиус 16, фон `rgba(255,255,255,0.72)` + backdrop-blur, бордер `#F2E6E2`
- Тень многослойная (см. 3.2)
- При наведении/тапе — подъём + масштаб 1.02

**Чипы/бейджи:**
- Радиус 20 (полностью круглые)
- Фон градиент персиковый, текст 11–13px, вес 600
- Отступы 6px×12px

**Прогресс-бар (квиз):**
- Высота 4–6, радиус 3
- Фон `#F2E6E2`, заполнение градиент коралловый
- Анимаця заполнения 300 мс `ease-out`

### 5.4 Иконки

- Стиль: линейные, 1.5–2 толщина, цвет `#1A1A1E` или акцент
- Размер: 16–24 (мини-апп), 24–32 (лендинг)
- Набор: слоты (верх/низ/обувь/сумка), маркетплейсы (4 логотипа), избранное, назад, закрытие

## 6. ЭКРАНЫ И КОМПОНЕНТЫ

### 6.1 Лендинг (структура)

1. **Хедер** (липкий): логотип + навигация + CTA «Открыть в Telegram»
2. **Hero:** H1 «Готовый образ за 10 сек — где купить дешевле» + 3D стопка карточек (Магнифик) + 2 кнопки + соцдок (50 образов · 4 маркетплейса · 2 мин)
3. **Боль:** 3 карточки (часы на WB, где дешевле, не садится) — появляются каскадом
4. **Как работает:** 3 шага (квиз → лента → кнопка) — номера в градиентных кругах
5. **Демо ленты:** 3–6 живых карточек с 4 ценами (из матрицы, не мокапы)
6. **Прайс:** 3 тарифа (199/299/499), средний «Популярный» подсвечен градиентом, якорь ~~990~~
7. **Соцдок:** отзывы/цифры (если есть) или «50 образов уже готовы»
8. **FAQ:** 3–4 аккордеона (дорого/размер/стиль/отмена)
9. **Финальный CTA:** «Открой 3 образа бесплатно» + кнопка

### 6.2 Мини-апп (4 экрана)

1. **Онбординг/квиз:** 3 шага (размер → стиль → бюджет), прогресс-бар, варианты как чипы, кнопка «Далее» градиент коралловый
2. **Лента:** masonry 2 колонки, карточки 4:5 с фото + бейджи цен (4 маркетплейса) + кнопка «Где купить», фильтры чипами сверху (учёба/офис/свидание/капсула), липкий хедер «Образ» + сердце (избранное)
3. **Карточка:** cover 4:5 + название + бюджет/повод/размер + слоты (топ/низ/обувь/сумка + альтернативы) с 4 ценами каждая + бейдж «нет в наличии — аналог» + липкая кнопка «Открыть 3 бесплатно» (если не подписан)
4. **Пейвол:** 3 тарифа (199/299/499) с якорем ~~990~~, средний подсвечен, кнопка «Оформить», доверие (МИР/СБП, чек, отмена), FAQ аккордеон, подпись ИП/оферта

### 6.3 Компоненты (общие)

- Кнопки (3 вида), карточки, чипы, бейджи цен, прогресс-бар, иконки, логотипы маркетплейсов
- Состояния: loading (скелетон с пульсацией), empty (иллюстрация + текст), ошибка (сообщение + кнопка повторить)

## 7. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- **Формат:** HTML/CSS/JS (для мини-аппа — один файл), лендинг — статичный или на Figma/Framer
- **Мобилка:** 360–430px, без горизонтального скролла, ретина
- **ТГ тема:** светлая/тёмная, контраст 4.5:1 минимум
- **Производительность:** <2с загрузка, анимации 60 fps, lazy-load изображений
- **3D:** Магнифик → Spline (1 материал, мягкий свет, изометрия), вес <500KB на сцену
- **Шрифты:** подключить через Google Fonts или локально (не больше 2)
- **Анимации:** CSS transitions/animations или GSAP (если нужна сложная), не больше 5 одновременных на экране

## 8. РЕФЕРЕНСЫ И ВДОХНОВЕНИЕ

- **Глубина и градиенты:** Stripe (тени, воздух), Apple (минимализм, типографика), Linear (градиенты, стеклянные карточки)
- **Мода:** Glossier (тёплый, женственный, мягкий), Pinterest (masonry, карточки 4:5), LTK/ShopMy (лента + кнопки купить)

- [ ] Прайс с якорем, средний подсвечен градиентом
- [ ] CTA каждые 1.5 экрана, липкий хедер
- [ ] <2с загрузка, <150KB hero

Мини-апп:
- [ ] 4 экрана (квиз, лента, карточка, пейвол) — все с анимациями
- [ ] Переходы: слайд снизу + прозрачность 300 мс

## 11. ЧТО НЕ ДЕЛАТЬ

- Холодный синий/серый — только тёплый кремовый/коралловый/персиковый
- Резкие анимации (линейные, >600 мс, дёргание)
- Плоский дизайн без глубины (нет теней, нет слоёв)
- Кислотные градиенты (неоновый, резкие переходы)
- Больше 2 шрифтов, больше 4 цветов + 1 акцент
- Мокапы вместо живых данных (в демо — реальные образы из матрицы)

## ИТОГ

Дизайн должен ощущаться как **премиум-модный продукт**: тёплый, живой, глубокий, с приятными всплывающими анимациями и мягкими градиентами. Каждая деталь работает на эмоцию «это моё, это дорого стоит, но доступно». Лендинг конвертит (в оплату), мини-апп удерживает (вовлечение, возврат). Глубина, градиенты, анимации — на каждой поверхности, в каждом элементе.
