# Obraz

Продукт для девушек: подбор готового образа и мгновенная покупка каждой вещи на Wildberries, Ozon, Lamoda и Яндекс Маркете.

Боль: девушка часами сидит в поиске WB и шерстит Pinterest, собирая образ по кусочкам, а потом ещё ищет, где каждую вещь купить. Решение: лента готовых образов (креаторы + ИИ), у каждой вещи - живая кнопка «где купить» с ценой и наличием. Креаторы собирают образы и получают процент с покупок своей аудитории - модель LTK / ShopMy, в РФ этой ниши нет.

Модель: приложение платное для пользовательниц (подписка); UGC-блогеры получают 15% с оплат подписок приведённой аудитории. Дополнительный доход - партнёрская комиссия маркетплейсов с вещей в образах. Цель - вырастить актив с метриками и продать стратегу дорого.

**Статус:** Этап 1 - фаза 0 (тест спроса): бот + пейвол + реф-система, техплан в `plans/2026-08-24-faza-0-bot-i-payvol.md`.
