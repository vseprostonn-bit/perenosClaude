# Мини-апп «Образ» - вёрстка

Собрано 03.09.2026 по брифу `docs/miniapp-brief-2026-09-03.md`. Не набор макетов,
а рабочее приложение: роутинг, состояние, Telegram SDK и слой данных по контракту.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | оболочка: подключение шрифтов, `telegram-web-app.js`, таб-бар, контейнер экранов |
| `styles.css` | вся визуальная система: палитра, тени, пружинки, тёмная тема Telegram |
| `api.js` | слой данных. Один контракт, две реализации - заглушки и реальные эндпоинты |
| `app.js` | экраны, роутинг, обработка событий, интеграция с Telegram |
| `01-04*.html`, `05-06*.html` | исходные наброски Yorren, оставлены как референс |

## Данные: живые или заглушки

Переключать ничего не нужно, режим определяется сам (`MODE = "auto"` в `api.js`):

- открыли внутри Telegram и бэкенд отвечает - работают реальные данные;
- открыли в обычном браузере или бэкенд недоступен - заглушки плюс плашка
  «демо-данные», чтобы это было очевидно.

Эндпоинты живут в `app/routes/miniapp.py`, авторизация - заголовок
`X-Telegram-Init-Data` с сырым `initData`, подпись проверяет
`app/services/telegram_auth.py`.

Как поднять на сервере - `docs/miniapp-zapusk-2026-09-03.md`.

## Экраны

- **Главная** - приветствие, переключатель «Себе / Ему», два действия, рейл «Образ дня»
- **Разбор** - загрузка фото, лоадер с шагами обработки, результат
- **Результат** - фото пользователя с вайбом, карточки вещей с процентом похожести,
  ценой, магазином, кнопками «Купить» и «≈ похожие», сумма образа
- **Образы** - лента с фильтрами по стилю и бюджету
- **Карточка образа** - состав с ценами и избранным
- **Избранное** - с пустым состоянием
- **Онбординг** - на первом входе: кому подбираем и размер, дальше не показывается
- **Профиль** - пол, размер, выбор магазинов, статус подписки
- **Тарифы** - 199 / 299 / 499, оплата уходит на getobraz.ru

## Женский и мужской сегменты

Решение владельцев 03.09.2026: женский сегмент главный, мужской - расширение
через него же (девушки собирают образ парню или мужу). В интерфейсе это
переключатель «Себе / Ему»: он меняет каталог в ленте и в разборе, значение
уходит в `gender` при запросах. По умолчанию женский.

## Telegram

Подключено: `ready()`, `expand()`, тёмная тема по `colorScheme`, `BackButton`
на вложенных экранах, `HapticFeedback` на действиях, `openLink` для внешних
ссылок (покупка и оплата открываются в браузере, а не внутри вебвью).

## Локальный просмотр

Любой статический сервер из этой папки, например:

```bash
python3 -m http.server 8123
```

Дальше `http://localhost:8123`. Проверялось в мобильном вьюпорте 375x812.
