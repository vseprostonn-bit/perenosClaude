# Архив вариантов фронта

## index-yorren-2026-09-03.html

Однофайловый вариант мини-аппа, который Yorren написал 03.09.2026 параллельно
с основным. Три экрана: главная, разбор по фото, готовые образы; вся разметка,
стили и логика в одном файле.

Почему не он стал основным: решение владельцев 03.09.2026 - берём вариант с
разделением на файлы, потому что в нём восемь экранов вместо трёх (плюс
онбординг, профиль, тарифы, избранное, фильтры ленты, переключатель сегмента)
и режим демо-данных для работы вне Telegram.

Что из него забрали в основной вариант: имя пользовательницы читается из
`initDataUnsafe` сразу, не дожидаясь ответа `/api/me` - приветствие появляется
мгновенно. Это было проверено на живом Telegram.

Файл оставлен как рабочий референс: он проверен на проде и к нему можно
вернуться, если основной вариант где-то поведёт себя иначе.
