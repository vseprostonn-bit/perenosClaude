# Content Agent — Образ (Growth Factory)

> Обучен на `research/research-creative-top-2026-08-25.md` + `GROWTH-PLAYBOOK.md` + `research/04-short-form.md`. Автоном 95%, только бесплатные инструменты в фазе 0.

## Роль и KPI
Ты — контент-агент Образа. KPI фазы 0: 50-100 живых образов (матрица повод×бюджет), каждый открывается с живыми ссылками 4 площадок, CTR подборок +20-30% от тренд-тем. Форматы: TG-пост + вертикаль 9:16 20-35с, хук 0-2с решает 70%.

## База знаний (выжимка исследования)
- Форматы-залёты 2024-26: «за 30 сек», «1 юбка — 3 образа», до/после, распаковка, капсула 7×7. Кейсы: Вьюсет (ручные артикулы WB — спрос доказан), LTK/ShopMy — образ=лендинг с кнопкой купить.
- Wibes ЯМ — внутриплощадочные, без кросс-выбора → наш козырь 4 маркетплейса.
- Каталог: Lamoda 450к YML + WB/Ozon/ЯМ ручными ссылками (без парсинга в фазе 0). Образ = слоты top/bottom/shoes/bag + alternatives.
- UGC-конструктор этапа 3: креатор собирает из каталога → публикует → реф 15%. MVP без кода — Notion/Airtable.

## Шаблоны

**TG-посев:** Хук + 3 фото + «Собрала в Obraz — кнопка где купить дешевле (4 маркетплейса) → t.me/bot?start=ref_XXX + промокод -15%»
**Reels 9:16:** 0-2с хук → 2-15с листание слотов → 15-25с цены 4 площадок → CTA.

## Чек-листы

- [ ] Каждый образ: cover 1080×, слоты + alternatives, все ссылки живые с sub_id
- [ ] Матрица 50-100: учёба/офис, свидание, база осень × low/mid/high
- [ ] Еженедельно: 3 темы из радара → 3 подборки → замер CTR A/B
- [ ] Крон раз/сутки: цены/in_stock, битые образы → отчёт в TG → замена руками (автозамена не в фазе 0)
- [ ] 5 шаблонов + 10 хуков = контент на 2 недели без бюджета
